# 왕들의 궤도 · KINGS’ ORBIT

**NØMAD / FIRST CONTACT — playable prototype 0.1.0**

고요한 우주를 떠돌다가 에덴에 내려앉는다. 파괴정으로 그곳을 헤집고, 원한다면 태양왕의 머리를 회수한다. 모선으로 돌아오면 다시 정적이다.

## 바로 실행

`index.html`을 Chrome, Edge 또는 WebGL 2를 지원하는 브라우저에서 연다. 실행에 필요한 코드·모델·셰이더·효과음이 모두 들어 있다. 인터넷에서 라이브러리, 모델, 이미지, 폰트를 내려받지 않는다. 별도 설치나 빌드 없이 실행할 수 있다.

파일 미리보기 앱이 아니라 실제 브라우저로 열어야 한다. 모바일 파일 뷰어가 JavaScript 실행을 제한한다면 정적 웹 호스팅에 `index.html`을 올려 실행한다. 페이지에 포함된 전체화면 버튼은 브라우저가 허용하는 환경에서만 작동한다.

`dist/kings-orbit.html`은 같은 게임의 배포용 복사본이다. GitHub Pages 등 정적 호스팅에는 루트의 `index.html` 하나만 올려도 된다. 이 패키지는 저장소를 만들거나 온라인 배포를 실행하지 않는다.

## 처음 한 바퀴

1. 모선에서 앞쪽 조종석으로 걸어가 **E**를 누른다.
2. **T**로 에덴에 자동항해한다. **E**로 일어나 전시실을 구경해도 항해는 계속된다.
3. 궤도에 도착하면 조종실 뒤쪽 복도를 따라 격납고로 가서 **E**로 파괴정에 탄다.
4. **좌클릭을 유지**하면 절단 광선. **Q**는 견인, **F**는 충격파. **Shift**를 누르고 건물에 충돌해도 부서진다.
5. 중앙의 거대한 황금 고리 앞에 태양왕이 있다. 왕좌를 공격해 무력화한 뒤, 머리를 바라보고 **Q**로 잡아 **S**로 물러나면 머리를 회수한다.
6. **R**로 귀환한다. 복도를 따라 앞쪽으로 가면 첫 번째 왼쪽 진열대에 머리가 전시된다. 가까이에서 **E**로 기록을 읽을 수 있다.

**왕을 잡거나 건물을 전부 부숴야 떠날 수 있는 게임이 아니다. R로 언제든 귀환할 수 있다.** 연료·목숨·제한시간은 없다.

## 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 선내 이동, 비행 |
| 마우스 | 시선·기체 방향 |
| 화면 클릭 | 마우스 고정 요청 |
| 우클릭 드래그 | 마우스 고정이 안 되는 환경의 시선 조작 |
| 방향키 좌우 | 회전 보조 |
| E | 조종석, 전시 기록, 출격, 조종석에서 일어나기 |
| Space / C | 비행 상승 / 하강 |
| Shift | 달리기 / 비행 가속·돌진 |
| T | 우주 자동항해 켜기·끄기 |
| X | 우주에서 추진 정지 |
| 좌클릭 유지 | 절단 광선 |
| Q | 바라보는 대상 견인, 다시 누르면 던져 놓기 |
| F | 근접 충격파. 재충전 3초 |
| R | 행성에서 모선 귀환 |
| Esc / P | 메뉴·일시정지 |

터치에서는 왼쪽 스틱으로 이동하고 오른쪽 빈 화면을 드래그해 시선을 움직인다. 광선 버튼은 길게 누른다. 여러 손가락으로 이동·고도 변경·발사를 함께 사용할 수 있다. 가로 화면을 권장하지만 세로 화면도 조작할 수 있다. DeX처럼 마우스와 터치를 혼용할 때는 메뉴에서 화면 터치 조작 표시를 직접 변경할 수 있다.

## 현재 구현 범위

- 자유롭게 걸어 다닐 수 있는 모선의 조종실, 트로피실, 격납고.
- 1인칭 우주 항해, 관성·가속·추진 정지, 자리를 떠나도 계속되는 자동항해.
- 행성 에덴 한 곳. 정원 도시, 외계 생명체 66개체, 파괴 가능한 건물 78개, 움직일 수 있는 소품.
- 1인칭 양팔 파괴정. 절단 광선, 중력 견인과 던지기, 충돌, 근접 충격파.
- 태양왕 무력화 → 머리에 견인선 연결 → 실제 후진으로 장력 증가 → 머리 회수.
- 회수한 머리의 조종석 옆 운반 표시, 모선의 실제 3D 전시, 전시 기록.
- 트로피와 건물 파괴 기록 저장. 재방문 시 복원, 트로피 중복 방지.
- 터치·키보드·마우스, 소리 전환, 일시정지, 그래픽 품질·시선 감도·화면 흔들림 설정.
- 저사양 모드. 균형 모드는 프레임 속도가 낮을 때 내부 렌더링 해상도를 단계적으로 낮춘다.
- 외부 음원 없는 합성 효과음. 우주에 음악이나 전투 음성을 계속 틀지 않는다.
- 로딩·오류·재시도 화면, 그래픽 연결 손실 처리.

이는 첫 행성까지의 프로토타입이다. 무한 우주, 다른 착륙 가능 행성, 거대로봇, 자유 메시 절단, 정교한 전신 로봇 애니메이션, 적 우주함대는 들어 있지 않다. 행성 전체의 구체 표면이 아니라, 접근 가능한 별도 지표 구역으로 전환한다. 우주 항해 구역과 지표 구역에는 경계가 있다. 장거리 지형·군중·건물·왕의 연출은 절차적으로 생성한 기하 모델이다.

## 저장

저장 키는 `kings-orbit-save-v1`이다. 왕의 머리 회수, 귀환, 주기적 항해, 페이지를 떠나는 시점에 저장한다. 이전 기록의 백업도 하나 유지한다.

브라우저의 파일 URL, 시크릿 모드, 저장소 정책에 따라 `localStorage`가 제한될 수 있다. 저장이 막혀도 플레이는 계속할 수 있고 안내가 표시된다. 메뉴의 **저장 내보내기**로 JSON 파일을 보관하고, **저장 불러오기**로 복원한다. 사이트 주소·호스팅 위치를 바꿀 때도 이 기능을 사용할 수 있다. 브라우저마다 서로 다른 저장소를 사용한다.

메뉴의 **진행 기록 초기화**는 확인 후 트로피와 파괴 기록을 모두 지운다.

## 소스 구조

```text
index.html                    완성된 단일 실행 파일
 dev.html                     수정용 진입점. 아래 소스를 직접 읽는다.
 src/
   core/
     math.js                  벡터·행렬·광선 충돌
     engine.js                WebGL 2, 인스턴싱, 절차 하늘·행성, 그림자·후처리
     input.js                 키보드·포인터 잠금·터치 입력과 취소 처리
     audio.js                 Web Audio 합성 효과음
     save.js                  검증·백업·자동 저장
   worlds/
     models.js                파괴정·조종석·왕의 머리·행성 모델
     interior.js              모선 내부와 보행 충돌·상호작용
     space.js                 우주 항해와 자동항해
   vehicles/destroyer.js       파괴정 조작과 견인 장력
   planets/
     registry.js              행성 등록과 별도 파일 로더
     eden.js                  에덴 지형·도시·생명체·왕·파괴·상태 복원
   ui/
     styles.css               반응형 화면과 터치 조작 UI
     template.html            UI 구조
     ui.js                    안내·메뉴·저장 내보내기·설정
   main.js                    씬 전환과 전체 플레이 흐름
 tools/build.py               소스를 단일 HTML로 묶는 빌더
 tests/                       자동 검증 스크립트·결과
 docs/                        구현·검증 메모
```

소스를 고친 뒤 실행:

```bash
python3 tools/build.py
```

`index.html`과 `dist/kings-orbit.html`이 갱신된다. npm 의존성이 없다.

`dev.html`에서 분리된 소스를 직접 확인하려면 다음처럼 로컬 정적 서버를 띄울 수 있다.

```bash
python3 -m http.server 8080
```

브라우저에서 `localhost:8080/dev.html`을 연다. 개발판은 에덴 진입 때만 `src/planets/eden.js`를 불러온다. 배포판은 이 파일도 미리 내장하므로 오프라인에서 작동한다.

## 행성 확장

행성 구현은 `src/planets/eden.js`에 독립되어 있다. 새 행성은 별도 파일에 등록할 수 있다. 현재 첫 버전의 항해 대상·트로피 모델은 에덴 하나에 맞춰져 있으므로, 새 행성을 추가할 때는 **등록부, 우주의 목적지, 트로피 모델 등록, 빌드 목록**도 함께 늘려야 한다. 파일 하나만 추가하면 새 행성이 자동으로 모든 화면에 나타난다고 가정하지 않는다.

자세한 계약과 확장 위치는 `docs/PLANET_MODULES.md`를 참고한다. 기존 게임의 핵심 입력과 렌더러를 새 행성마다 복사하지 않도록 분리했다.

## 검증과 한계

`docs/TEST_REPORT.md`에 검증 방법과 범위를 적었다. 실제 WebGL 렌더링, 브라우저 입력, 출격·파괴·머리 회수·귀환, 재방문, 터치 동시 입력과 취소 처리를 점검했다.

테스트 기기는 데스크톱 Chromium의 소프트웨어 GPU와 터치 에뮬레이션이다. 특정 휴대전화나 샤오신패드에서의 실제 프레임 속도를 측정한 것은 아니다. 검증 환경의 URL 탐색 제한 때문에 HTML을 테스트 페이지에 주입하고, 저장 검증에는 메모리 기반 Web Storage 어댑터를 사용했다. 실제 파일 URL·실제 호스팅 주소의 장기 저장과 다운로드 UI 동작은 별도 실기기 확인이 필요하다.

`?debug=1`을 주소 뒤에 붙이면 디버그 계측과 `window.__KO__` 개발 인터페이스를 사용할 수 있다. 일반 실행에서는 이 인터페이스를 열지 않는다.

## 외부 자산

별도 이미지·3D 모델·음원·폰트 파일을 포함하지 않는다. 시각 모델은 코드로 생성하고, UI 글꼴은 기기에 있는 시스템 글꼴을 사용한다. 런타임 라이브러리 의존성이 없다.
